# 연구계획서: 응답 단위 미지원 상태와 근거 표시 거절

> run `cot45_public_run_20261029_154552` · candidate 6 · CoT5 판정 NOVEL (검색 범위 한정, 부록 참고)
> 3단계 심사를 거치지 않은 plan으로 작성했다.

## 0. 개요

**연구 주제.** 검색 근거 전체가 질의를 뒷받침하지 못하는 상태를 응답 단위로 학습하고, 그 상태에서 근거를 표시한 거절 또는 외부 지식 요청을 생성하는 검색 증강 생성

검색 증강 언어모델은 찾아온 문서로 답할 수 없을 때도 답을 만들어 내는 경향이 있다. 이 연구는 검색한 근거 전체가 질문에 답하기에 부족한지를 모델이 응답 단위로 판단하도록 학습하고, 그렇다면 무엇을 검토했고 무엇이 부족한지 근거와 함께 밝히며 거절하거나 추가 정보를 요청하게 하는 방법을 계획한다. 가장 가까운 선행연구인 Self-RAG의 기존 신호만으로 같은 일을 할 때와 비교해 새 상태가 필요한지 검증하고, 답할 수 있는 질문에서 불필요한 거절이 늘지 않는지도 확인한다.

## 1. Proposed Method

### 1.1 문제 정의 및 연구 배경

**현재 방식.** RAG [2005.11401]는 검색한 문서를 조건으로 답을 생성하고, 생성에 쓴 문서를 근거로 보여주는 것을 목표로 한다. Self-RAG [2310.11511]는 reflection token으로 검색 여부를 정하고, 문서의 관련성과 생성한 문장 조각이 문서에 의해 지지되는지를 스스로 평가한다.

**한계.**
- L1. Self-RAG는 사람 평가(S&P)에서 모델이 irrelevant 또는 no support를 예측한 사례를 고려하지 않았다고 밝힌다. 따라서 그 평가는 근거가 없다고 판단된 경우의 응답 품질을 보여주지 않는다. [2310.11511]
- L2. Self-RAG의 지지 판단은 생성한 문장 조각과 개별 문서 사이에서 이루어지고, 생성 중 조각을 고르는 데 쓰인다. 근거 문서 집합 전체가 질의에 답하기에 부족한지를 응답 단위로 판단해 응답 방식을 바꾸는 장치는 이 논문의 목표에 포함되어 있지 않다. [2310.11511]
- L3. 근거 없는 주장을 다루는 관련 연구는 생성한 뒤에 주장을 탐지하거나(ORION) 인용 오류를 교정한다(FineRef). 생성 시점에 응답 방식을 거절이나 외부 지식 요청으로 바꾸지는 않는다. [2504.15771; 2602.18437]
- L4. 근거가 부족할 때 질의를 바꿔 검색을 반복하는 방식(Self-MedRAG)은 근거가 끝내 없을 때의 응답 형식을 다루지 않는다. [2601.04531]

**연구 질문.** '미지원 질의'를 검색된 근거 문서 집합 안에 정답을 뒷받침하는 문서가 없는 질의로 정의할 때, 응답 단위의 미지원 상태를 학습한 모델은 Self-RAG의 기존 지지 판단 신호만 쓰는 방식보다 미지원 질의를 더 정확히 가려내고, 무엇을 검토했고 무엇이 부족한지 근거를 표시해 거절하거나 외부 지식을 요청하는가?

**연구 목표.** 근거가 질의를 뒷받침하지 못하는 경우를 투명하게 처리하기 위해 응답 단위 미지원 상태와 그 학습 데이터 구성, 근거 표시 거절 생성 방법을 개발하고, 미지원 판별 정확도, 거절 응답의 근거 표시 품질, 답변 가능한 질의에서의 성능 유지로 검증한다.

### 1.2 제안 방법

Self-RAG [2310.11511]의 reflection token 체계에 응답 단위 미지원 상태(M1)를 더하고, 이를 학습할 짝 데이터(M2), 상태에 따라 응답 방식을 고르는 규칙(M3), 근거를 표시한 거절·요청 생성(M4)으로 구성한다.

#### 1.2.1 M1: 응답 단위 미지원 상태 토큰

근거 문서 집합 전체가 질의에 답하기에 부족한지를 예측하는 상태 토큰. 어휘 확장과 미세조정으로 학습한다. (L2 대응)

#### 1.2.2 M2: 짝 지은 미지원 학습 데이터 구성

답변 가능한 질의에서 정답 근거 문서를 제거하거나 무관한 문서로 바꿔 미지원 사례를 만들고, 원래 사례와 짝지어 라벨을 붙인다. 평가용 질의는 학습용과 다른 출처에서 따로 만든다. (L1, L2 대응)

#### 1.2.3 M3: 상태 기반 응답 결정 규칙

미지원 상태 확률의 임계값으로 답변과 거절을 고른다. 임계값으로 거절률과 답변 성능의 균형을 조절한다. (L2, L4 대응)

#### 1.2.4 M4: 근거 표시 거절·요청 생성

거절이나 외부 지식 요청에 검토한 문서와 부족한 정보를 근거 표시와 함께 쓴다. 근거가 될 문서가 없으면 근거를 지어내지 않고 그 사실을 밝힌다. (L1, L3 대응)

#### 구성요소 관계

- M2 → M1: M2가 만든 짝 라벨로 M1을 학습한다
- M1 → M3: M1의 상태 확률이 M3의 결정 신호가 된다
- M3 → M4: M3가 거절을 고르면 M4가 근거 표시 거절·요청을 생성한다

## 2. Validation & Target Claims

### 2.1 Experimental Validation Plan

**검증 대상**
- V1. M1은 B3(기존 지지 신호 기반 판정)보다 미지원 질의를 더 정확히 가려내는가? (M1, M3)
- V2. M2의 짝 데이터로 학습하면 기존 라벨만으로 학습한 B5보다 미지원 판별이 나아지는가? (M2)
- V3. M4의 거절 응답은 B3, B4보다 표시한 근거가 실제로 그 문장을 뒷받침하고 부족한 정보를 정확히 밝히는가? (M4)
- V4. 답변 가능한 질의에서 제안 방법은 B1, B2보다 불필요한 거절을 늘리지 않으면서 정확도를 유지하는가? (M3)

**비교 대상**
- B1. RAG [2005.11401] — 근거 부족을 판단하지 않고 항상 답하는 기본 검색 증강 생성
- B2. Self-RAG [2310.11511] — reflection token을 쓰는 가장 가까운 선행연구 원본
- B3. Self-RAG 기존 지지 신호 기반 거절 [2310.11511] — 새 상태 없이, 모든 문장 조각에서 IsSup가 no support이거나 모든 문서에서 IsRel이 irrelevant이면 거절하고 M4와 같은 근거 표시 형식을 쓴다. 응답 단위 상태가 필요한지 가리는 핵심 ablation
- B4. 생성 후 탐지 뒤 거절 [2504.15771] — 답을 생성한 뒤 근거 없는 주장을 탐지해 거절로 바꾸는 방식. 판단 시점의 차이를 비교한다
- B5. 기존 라벨만으로 학습한 M1 — M2의 짝 데이터 대신 Self-RAG의 기존 지지 라벨만으로 M1을 학습한다. 데이터 구성 방법(M2)이 필요한지 가린다

### 2.2 Target Claims

- **C1.** 응답 단위 미지원 상태는 Self-RAG의 기존 지지 신호보다 미지원 질의를 더 정확히 가려낸다.
  - 반증 조건: E1에서 B3 대비 유의한 F1 차이가 없으면 기각
  - 검증: V1
- **C2.** 짝 지은 미지원 데이터는 기존 라벨보다 미지원 판별 학습에 효과적이다.
  - 반증 조건: E2에서 B5 대비 우위가 없으면 기각
  - 검증: V2
- **C3.** 근거 표시 거절은 기존 신호 기반 거절과 생성 후 탐지 방식보다 정확한 근거를 제시한다.
  - 반증 조건: E3에서 B3, B4 대비 우위가 없으면 기각
  - 검증: V3
- **C4.** 적절한 임계값에서 답변 가능한 질의의 정확도는 허용 폭 안에서 유지된다.
  - 반증 조건: E4에서 허용 폭 이내의 임계값이 없으면 기각
  - 검증: V4

### 2.3 Expected Novelty & Contribution

**신규성**
- Self-RAG가 생성한 문장 조각마다 지지 여부를 판단하는 것과 달리, 근거 문서 집합 전체에 대한 응답 단위 상태를 학습해 응답 방식을 바꾼다. [2310.11511]
  - 기존 장치: Self-RAG의 IsSup 토큰: 생성한 문장 조각마다 문서의 지지 여부를 fully/partially/no support로 판단하고 조각 선택에 쓴다 · 차이: 적용 단위 · 검증: E1
- 생성한 뒤 근거 없는 주장을 탐지하거나 인용을 교정하는 방식과 달리, 생성 시점에 거절이나 외부 지식 요청으로 응답 방식을 바꾼다. 검토한 문헌 범위에서 이 조합은 확인되지 않았다. [2504.15771; 2602.18437]
  - 기존 장치: ORION의 생성 후 근거 없는 주장 탐지, FineRef의 생성 후 인용 오류 반성·교정 · 차이: 적용 시점 · 검증: E3

**기여**
- **방법.** 응답 단위 미지원 상태와 근거 표시 거절·요청 생성 방법
- **자원.** 답변 가능·미지원 사례를 짝지은 학습 데이터 구성 절차
- **분석.** Self-RAG 기존 신호 대비 비교와 거절률-정확도 균형 분석
