# 명령어.md

아래는 `ZZZ_실험단계자세히.md` 흐름을 따라 이번에 **OpenRouter provider로 재실험**하면서 사용한 명령어입니다.

## 실행 정보

- 작업 위치: `/mnt/d/NEW_HARNESS_INNOVATION`
- 최종 복사 대상: `D:/새로운하네스실험` (`/mnt/d/새로운하네스실험`)
- 임시 작업 패키지: `/mnt/d/NEW_HARNESS_INNOVATION/새로운하네스실험_패키지`
- RUN_ROOT: `/mnt/d/NEW_HARNESS_INNOVATION/experiment_work_openrouter/run_root`
- RUN_ID: `exp-openrouter-5papers-20260707`
- Provider: `openrouter`
- verification-depth: `selected_only`
- 자동 선택 후보: `cand-r1-1`
- `.env.local`: 사용자가 요청한 대로 파일 내용을 확인/출력하지 않았고, CLI 자동 로드만 사용했습니다.

## 2. OpenRouter run 실행

```bash
rm -rf "$RUN_ROOT"
mkdir -p "$RUN_ROOT"
python3 -m new_harness.cli run   --input "$WORK_ROOT/01_실험입력_5개_arxiv.json"   --run-id "$RUN_ID"   --run-root "$RUN_ROOT"   --provider openrouter   --verification-depth selected_only | tee "$WORK_ROOT/02_run_실행결과.json"
```

참고: 첫 실행은 샌드박스 DNS 제한으로 실패했고, 같은 명령을 네트워크 허용 상태에서 재실행해 아래 성공 결과를 얻었습니다. `.env.local` 값은 확인하거나 출력하지 않았습니다.

실행 결과 요약:

    "selection_options.json",

  ],
  "error": null,

      "cand-r1-1",
