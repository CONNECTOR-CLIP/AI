# 명령어.md

OpenRouter provider + strong_external + D:/SearchEngine 실제 검색 재실험 명령 기록입니다.

## 실행 정보

- RUN_ID: `exp-openrouter-search-engine-strong-20260707`
- Provider: `openrouter`
- verification-depth: `strong_external`
- external-checker: `search_engine`
- SearchEngine URL: `http://127.0.0.1:8000/search`
- Python/uvicorn: `D:/.venv-local-win`
- OpenSearch: `D:/opensearch-2.13.0`, bundled JDK 사용
- `.env.local`: 파일 내용을 확인/출력하지 않았고, CLI 자동 로드만 사용했습니다.

## 서버 실행

```bash
/mnt/d/.venv-local-win/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
cmd.exe /c "set OPENSEARCH_JAVA_HOME=D:\opensearch-2.13.0\jdk&& set JAVA_HOME=D:\opensearch-2.13.0\jdk&& cd /d D:\opensearch-2.13.0 && bin\opensearch.bat"
```

서버 확인 결과: OpenSearch `green`, SearchEngine `ok`.

## run 명령

```bash
/mnt/d/.venv-local-win/Scripts/python.exe -m new_harness.cli run \
  --input "D:\NEW_HARNESS_INNOVATION\experiment_work_search_engine_strong\01_실험입력_5개_arxiv.json" \
  --run-id "exp-openrouter-search-engine-strong-20260707" \
  --run-root "D:\NEW_HARNESS_INNOVATION\experiment_work_search_engine_strong\run_root" \
  --provider openrouter \
  --verification-depth strong_external \
  --external-checker search_engine \
  --external-search-url "http://127.0.0.1:8000/search" \
  --external-max-results 5 \
  --external-timeout 20 \
  --external-min-interval 0.5
```
