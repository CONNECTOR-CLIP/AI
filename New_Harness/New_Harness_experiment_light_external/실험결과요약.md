## strong_external 대비 차이점

- `pass_candidate_ids`는 두 실험 모두 `cand-r1-1`, `cand-r1-2`, `cand-r1-3` 3개로 동일합니다(같은 입력/논문 정규화/evidence card/후보생성/후보비평 결과이므로 결정적으로 동일).
- `strong_external`은 pass 후보 3개 전부를 SearchEngine으로 외부 검증했지만(`external_check_count: 3`), `light_external`은 문서(`ZZZ_실험단계자세히.md` 12절)에 명시된 대로 "pass/near-pass 후보 일부만" 검증하여 `cand-r1-1`, `cand-r1-2` 2개만 검사했고 `cand-r1-3`은 `external_checks/round_1/`에 파일이 생성되지 않았습니다.
- 두 실험 모두 `duplicate_risk: low`, `degraded_reason: null`로 정상 검증되었고, SearchEngine/OpenSearch degraded 처리는 발생하지 않았습니다.
- select/draft/qa_suggest/auto_edit는 `strong_external`과 동일한 후보(`cand-r1-1`)와 동일한 revise 요청 문구로 진행했으며, 요청 문구가 같아 revision record 해시(`qa_suggest-9c10012eb139`, `auto_edit-0934767e98a9`)도 동일하게 재현되었습니다.
- 산출물 파일 수는 `light_external`이 50개로, `strong_external`(52개)보다 external_checks 파일 2개(사람이 보는 사본 1개 + 원본 runs 사본 1개) 적습니다.
